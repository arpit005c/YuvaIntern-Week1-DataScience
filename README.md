# YuvaIntern Week 1 - Data Science Using Python

## Air Quality Data Acquisition, Cleaning and Preprocessing

This project was completed as part of the Week 1 Data Science using Python internship task.

### Objective

The objective of this project is to acquire a publicly available air-quality dataset, investigate its quality, clean invalid and missing values, analyze outliers and distributions, and prepare the dataset for further analysis.

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Dataset

The project uses an air-quality dataset containing pollutant, sensor and meteorological measurements.

### Data Cleaning

The major preprocessing steps included:

- Initial dataset exploration
- Missing-value analysis
- Identification of `-200` invalid values
- Treatment of invalid values
- Handling of highly incomplete features
- Date and time processing
- Duplicate checking
- Outlier analysis
- Final data-quality validation

### Final Dataset

After preprocessing:

- Rows: 9,357
- Columns: 15
- Missing values: 0
- Invalid `-200` values: 0
- Duplicate rows: 0

### Exploratory Data Analysis

The project includes:

- Numerical feature distributions
- Outlier analysis
- Temperature and humidity trends
- CO concentration over time
- CO vs NOx relationship
- Correlation heatmap

### Project Files

- `notebook/` - Jupyter Notebook

- `report/` - Week 1 technical report
