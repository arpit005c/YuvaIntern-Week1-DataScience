# House Price Prediction Using Regression

## Project Overview
This project uses Machine Learning regression algorithms
to predict median house values using the California
Housing dataset.

## Objectives
- Explore and analyze housing data.
- Perform exploratory data analysis.
- Train and compare regression models.
- Tune Random Forest hyperparameters.
- Evaluate model performance.
- Analyze prediction errors and feature importance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Joblib

## Machine Learning Models
1. Linear Regression
2. Ridge Regression
3. Gradient Boosting
4. Random Forest
5. Mean Baseline

## Final Model
Tuned Random Forest Regressor

## Final Performance

| Metric | Result |
|---|---:|
| MAE | 0.3263 |
| RMSE | 0.5019 |
| R2 Score | 0.8077 |
| R2 Percentage | 80.77% |

## Dataset
California Housing Dataset from Scikit-learn.

- data/

## Limitations
The dataset has an upper cap on recorded house values.
Predictions should be interpreted with this limitation
in mind.
